# Evolutionary trajectory and momentum shape prostate cancer outcomes

This repository contains all the code necessary to reproduce the figures (main, extended and supplementary) of the manuscript **Evolutionary trajectory and momentum shape prostate cancer outcomes** from the Pan Prostate Cancer Group (PPCG). Running the scripts in `scripts/` reproduces all the analyses in the manuscript; helper functions are located in `src/`; metadata, raw and processed data are organised under `data/`. The pipelines used to process raw data, and their corresponding code, are described in a companion publication by Jakobsdottir et al.

## Reproducing the figures

> **Note:** all source data needed to regenerate the published panels are available at the following private figshare link: <https://figshare.com/s/058ba7d313d13b144357>. Download all files and save them under `figures_data/` (flat, no subfolders), then follow steps 1, 3 & 4 below.

Strict data protection policies prevent redistribution of raw patient-level data (see [Data availability](#data-availability)); the source-data files above contain only the pre-computed plotting inputs for each panel.

1. Create and activate the `ppevo` conda environment (skip the first command if the environment already exists):
   ```bash
   conda env create -f envs/ppevo.yaml
   conda activate ppevo
   ```
2. Place all `*_source_data.{tsv,rds}` files in `figures_data/` (flat — no subfolders). 

   a. If you have already run the full analysis scripts, populate the folder with:
      ```bash
      mkdir -p figures_data
      find outputs -name "*_source_data.*" -exec cp {} figures_data/ \;
      ```
   b. If you have downloaded source data from figshare repository, please save all files under `figures_data/` (flat, no subfolders)

3. From the repo root, run:
   ```bash
   Rscript scripts/reproduce_figures.R
   ```
4. All published panels appear under `figures/reproduced/`.

Schematic panels (Fig1b, Fig2a, Fig4c, Fig5b, EXDF10a) are not generated by code.

## Repository layout

- `data/` — raw, processed, metadata and QC files (see the data-availability section below).
- `scripts/` — analysis code, grouped into numbered sub-folders mirroring the manuscript sections.
- `src/` — helper functions sourced by the scripts in `scripts/`.
- `figures/` — figures generated by the scripts.
- `outputs/` — intermediate and final tabular outputs generated by the scripts.
- `figures_data/` — minimal source-data files (one `<panel>_source_data.{tsv,rds}` per published panel) required to regenerate every figure via `scripts/reproduce_figures.R`. Each file contains only the plotting input used by the corresponding panel, not the upstream computation.
- `envs/` — conda environment specifications (see the Software environment section below).
- `SigTimeR-main/` — `SigTimeR` R package used to time mutational signatures, following the approach previously described in PCAWG.

## Software environment

Analyses were run with R 4.2.2 inside the `ppevo` conda environment. The full pinned package list is specified in [`envs/ppevo.yaml`](envs/ppevo.yaml); recreate the environment with:

```bash
conda env create -f envs/ppevo.yaml
conda activate ppevo
```

## Data availability

**Strict data protection policies govern the PPCG, HMF and HEROIC cohorts used in this study, so public distribution of raw sequencing data and intermediate patient-level somatic variant calls is not possible.** Access can be requested per cohort:

- **Pan Prostate Cancer Group (PPCG)** — https://panprostate.org/data.html
- **Hartwig Medical Foundation (HMF)** — https://www.hartwigmedicalfoundation.nl/en/data/data-access-request/
- **HEROIC** — DNA-sequencing data are deposited at the European Genome-Phenome Archive (EGA) under overarching accession `EGAS00001006425`, as detailed by Weerachai et al., Nature 2022.
